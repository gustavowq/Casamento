# Casamento

Convite digital de Emily e Augusto: [abrir o site](https://gustavowq.github.io/Casamento/).

O GitHub Pages publica o conteúdo de `convite-emily-lucas/` na raiz do endereço acima. Cada alteração nessa pasta enviada à branch `main` inicia uma nova publicação pela [ação de deploy](.github/workflows/pages.yml). A publicação também pode ser iniciada manualmente na aba Actions do GitHub.

Para testar localmente, abra `convite-emily-lucas/index.html` com um servidor HTTP, como o Live Server do VS Code.
